# Security policy

Foyer Manager handles household money data. We take security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Preferred: [report it privately on GitHub](https://github.com/Mikawx3/foyer-manager/security/advisories/new).
- Or email **foyer-manager@gmail.com** with the subject `SECURITY`.

Include the affected endpoint or page, steps to reproduce, and the impact you observed.
You will get an acknowledgement within 72 hours. We will keep you updated until a fix ships
and credit you in the release notes if you wish.

## Scope

- The code in this repository.
- The hosted instance at [allotwe.com](https://allotwe.com). Test only with accounts and
  households you created yourself. No denial of service, spam, or social engineering.

## Supported versions

Only the latest commit on `main` is supported. Self-hosted instances should update regularly.
